These transparent PNG marks are rendered from `FaLinkedinIn`, `FaThreads`, and
`FaBluesky` in the project's `react-icons/fa6` dependency (Font Awesome Free
brand icons, CC BY 4.0). See https://fontawesome.com/license/free.

The demo artwork and animation are original. Re-render both video formats and
the poster with `python3 scripts/render-hero-demo.py` (Pillow and FFmpeg required).
The generator uses Arial on macOS or DejaVu Sans on Linux; `MEADOW_FONT_DIR`
can point to a directory containing `Arial.ttf` and `Arial Bold.ttf`.

The 34-second v2 demo shows direct publishing and a custom chatbot connected to
Meadow’s REST publishing API. The chatbot is illustrative; the MCP integration
currently supports drafting, while the REST API supports publishing. No live
accounts are used or posts sent when rendering the video.
