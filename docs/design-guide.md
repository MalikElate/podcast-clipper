# Meadow design reference

Use the user’s [Woodbark app design guide](https://woodbark-design-guide.vercel.app), hosted on Vercel. This is a separate document from Vercel’s general interface guidelines.

Keep Meadow’s existing color theme unless the user requests a palette change.

- Explain the product directly; avoid templated three-step walkthroughs and three-card feature explanations. Prefer the existing product demo or useful interface.
- Let headings stand alone, without decorative overlines or badges.
- Do not add decorative dots or check marks to labels or lists. Use plain text and spacing.
- Display authentic third-party logos without extra tiles or background boxes.
- Illustrative artwork should be custom and recognizable, in the app’s style. Keep authentic brand logos intact.
- Keep functional controls and useful status information: checkboxes, playback buttons, form labels, and publishing status still serve a purpose.
