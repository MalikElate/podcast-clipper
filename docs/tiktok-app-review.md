# TikTok app review

## Review explanation

The following copy is 949 characters and fits TikTok's 1,000-character limit:

> Meadow is a social media publishing workspace. Users click Connect TikTok and are redirected to TikTok Login Kit to authorize their own account. With user.info.basic, Meadow retrieves the authorized user's open ID, display name, and avatar so the user can identify the connected account. With video.publish through Content Posting API Direct Post, the user selects a video/photo created or uploaded in Meadow, reviews the caption and TikTok-required privacy, interaction, branded-content, AI-content, and music-consent settings, then clicks Publish or Schedule. Meadow sends the media from our verified domain to TikTok, receives a publish ID, checks status, and shows success or failure. With video.list (Display API), Meadow queries an already published public TikTok post by its ID to show view, like, comment, and share counts in the user's analytics. Data is used only for the authorized user's account. Users may disconnect TikTok at any time.

## Demo video checklist

1. Open Meadow on `https://findmeadow.com/`.
2. Connect a TikTok account and show the TikTok authorization screen.
3. Return to Meadow and show the connected account's display name and avatar.
4. Select a video or photo and complete the TikTok publishing controls.
5. Publish the content and wait for Meadow to report completion.
6. Show the post in TikTok.
7. Return to Meadow and show the post's analytics.

For a first review, record this flow with the TikTok sandbox. The recording must show every selected product and scope.
